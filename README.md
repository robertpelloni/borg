# borg

**"Borg" is a historical name, not a separate project.** It was an earlier name for the agent-orchestration work that became TormentNexus/HyperNexus — the same codebase lineage, renamed. Do not treat Borg as its own active project.

## Status

This repository is an **empty placeholder** — the name is reserved here, but no code has ever been pushed to it. Its only file is this README (single commit, 2026-10-22). There is nothing to build or run here.

## Where the work actually lives

- [`MDMAtk/TormentNexus`](https://github.com/MDMAtk/TormentNexus) — the canonical open-source repo (TormentNexus is the original; HyperNexus is a rename plus cloud hosting / thin commercial facade)
- [`HyperNexusLLC/HyperNexus`](https://github.com/HyperNexusLLC/HyperNexus) — the commercial-facing tree
- [`robertpelloni/workspace`](https://github.com/robertpelloni/workspace) — the federated monorepo, which contains a `borg` component (multi-agent choreography bus)
- [`robertpelloni/hyperharness`](https://github.com/robertpelloni/hyperharness) — the Go harness/control-plane work, which carries Borg session/queue state
